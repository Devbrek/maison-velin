Maison Vélin est la vitrine de trois templates de sites pour la joaillerie, l'horlogerie et le parfum, chacun démontré sur une marque fictive. Une création [Devbrek](https://devbrek.fr).

**En ligne :** [maison-velin.vercel.app](https://maison-velin.vercel.app)

**Stack :** Astro 7 (site statique), îlots React 19, Tailwind CSS 4, TypeScript, Vitest, hébergement Vercel.
