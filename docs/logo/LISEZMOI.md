# Logo Maison Vélin

Concept : une **porte en arche** à double filet, comme le seuil d'une maison. Elle encadre un V en Bodoni Moda et un losange qui évoque une pierre sertie.
L'arche fait aussi écho à celles de la démo Calade.

## Fichiers
- `svg/monogramme.svg` / `-clair` : l'arche seule (petits formats, avatar)
- `svg/horizontal.svg` / `-clair` : arche + « MAISON Vélin BY DEVBREK » (en-tête, carte projet)
- `svg/navbar.svg` / `-clair` : **version simplifiée pour la barre de navigation** (traits épaissis, sans « BY DEVBREK »), nette dès 40 px de haut
- `svg/vertical.svg` / `-clair` : version empilée
- `svg/favicon.svg`, `png/favicon-32.png`, `png/apple-touch-icon-180.png` : icônes d'onglet et d'écran d'accueil
- `png/carte-projet-*.png` : vignettes 1600×900 (jour, nuit, et `portfolio` sur fond #0A0F1E)
- `png/monogramme-*.png` : 512×512
- `svg/carre-*.svg` + `png/carre-*-1024.png` : **formats carrés 1024×1024**
  - `carre-complet-*` : arche + « MAISON Vélin BY DEVBREK » (jour, nuit, portfolio #0A0F1E, transparent)
  - `carre-monogramme-*` : arche seule (jour, portfolio)

`-clair` = pour fond sombre.

## Couleurs
- Encre `#141311`, vélin `#F3EEE4`, bleu encre `#1C2A4A` (« by Devbrek »)
- Nuit : `#0F0E0C`, vélin `#EDE8DF`, bleu pâle `#9DB2DE`

## Notes
- Le texte est vectorisé : aucune police n'est nécessaire pour afficher le logo.
- Polices d'origine : Bodoni Moda et Jost, licence libre OFL (utilisation dans un logo autorisée).
- Taille minimale conseillée : 24 px pour le monogramme, 40 px pour `navbar`, 72 px pour `horizontal` (sinon « BY DEVBREK » devient illisible).
